Scenario 2: Single Queue vs. Size-Based Queues (WITH Size-to-Table Matching)
The problem addressed: Even with strict size-to-table matching (groups only sit at correctly sized tables), a single FCFS queue still causes large groups to wait longer because small groups ahead of them in the queue occupy all the small tables, and large groups cannot "jump ahead" to available large tables.

Key insight: The blocking happens in the queue order, not in table assignment.

# Scenario 2 - Run A: Single queue with strict size matching
# PROBLEM: Large groups wait behind small groups in FCFS queue

tables = 2,2,2,2,4,4,6,6
servers = 3
kiosks = 0
ordering_type = counter_only
reservation_policy = none

# SINGLE QUEUE - CAUSES BLOCKING
walkin_queue_discipline = single_queue

# STRICT SIZE-TO-TABLE MATCHING (same in both runs)
seating_policy = exact_size_match

counter_order_time_min = 2
counter_order_time_max = 3
food_prep_time_min = 8
food_prep_time_max = 12
abandonment_threshold_minutes = 30
abandonment_rate_at_threshold = 0.50

# Scenario 2 - Run B: Size-based queues with strict size matching
# SOLUTION: Separate queues prevent large groups from waiting behind small groups

tables = 2,2,2,2,4,4,6,6
servers = 3
kiosks = 0
ordering_type = counter_only
reservation_policy = none

# SIZE-BASED QUEUES - THE SOLUTION
walkin_queue_discipline = size_based
size_queue_1_min = 1
size_queue_1_max = 2
size_queue_2_min = 3
size_queue_2_max = 4
size_queue_3_min = 5
size_queue_3_max = 6

# STRICT SIZE-TO-TABLE MATCHING
seating_policy = exact_size_match

counter_order_time_min = 2
counter_order_time_max = 3
food_prep_time_min = 8
food_prep_time_max = 12
abandonment_threshold_minutes = 30
abandonment_rate_at_threshold = 0.50

Expected Metrics (With Strict Matching in Both)
Metric	                         Run A (Single queue)	Run B (Size queues)	Improvement
Large group (size 6) avg wait	      28 min	                  14 min	↓ 50%
Large group max wait	              45 min	                  22 min	↓ 51%
